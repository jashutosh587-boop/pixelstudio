About the project

Everyday photo tools, in one simple studio.

PixelCraft Studio is a browser-based image workspace for common photo tasks. It brings live cropping, resizing, image adjustments, filters, transforms, text and watermarks, stickers, frames, batch processing, compression, format conversion, print-size photo preparation, simple background color removal, collages and meme creation into one interface.

Designed around privacy

Selected image files are processed locally using browser image APIs. The tools in this build do not send photo files to a PixelCraft image-processing server. The hosting provider and external interface CDNs may still process routine connection information.
