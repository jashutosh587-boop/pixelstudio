Privacy Policy

Last updated: 4 November 2026

In plain language: Image files selected for editing are processed locally in your browser. This static build does not upload those image files to a PixelCraft image-processing server. The website does use its hosting provider and external CDNs to deliver the page and its interface assets.

1. Image files and local processing

PixelCraft Studio uses browser image APIs, including Canvas and image decoding features, to crop, resize, adjust, convert and export images on your device. The image tools in this build do not send selected image files to a PixelCraft processing server. Your images are held in browser memory while you work. Downloads and project JSON files are created by your browser when you choose to save them.

Do not use a shared or public device for sensitive images unless you understand its local download, browser and device-storage settings. Closing the page normally ends the current editing session; files you download or projects you save remain wherever your browser saves them.

2. Information handled to operate the website

The website is hosted as a static site. The hosting provider may process ordinary technical request data such as IP address, request time, browser, device and requested page in server logs for delivery, security and reliability. Review the hosting provider's current privacy information for its practices.

The page loads interface assets from public CDNs (including Tailwind CSS and Lucide icons). Those CDN providers may receive standard connection information when your browser requests the assets. These requests do not transmit the image files you edit through PixelCraft's local tools.

3. Local storage and cookie preferences

PixelCraft stores your cookie preference selection in your browser's local storage so the preference banner can remember your choice. Essential preference storage is always used. This build does not include an analytics SDK or active advertising script. Selecting an optional category records your preference but does not itself activate tracking or advertising in this version.

You can reopen Cookie settings from the website footer and change your preference. Clearing browser site data also removes the saved preference.

4. Advertising and analytics

Advertisement spaces currently show placeholders only. No Google AdSense ads or analytics tags are activated in this supplied build. If the site operator later adds advertising or analytics services, this policy must be updated to describe the actual providers, purposes, cookies or similar technologies, data use and available choices before those services are enabled.

Where a law or advertising platform requires a certified consent-management platform or a particular consent signal, the operator must deploy an appropriate compliant CMP and ensure that optional tags respect the visitor's choice. The simple preference panel included here is not a certified CMP and should not be treated as one.

You may use the editor without creating an account. You can decline optional categories using Cookie settings. For a question about this website or a privacy request, contact the site operator using the address below.

6. Children

PixelCraft Studio is a general-purpose image utility and is not intentionally designed to collect personal information from children. A parent or guardian may contact the operator with a concern.

7. Changes to this policy

This policy may be updated when website features, hosting, advertising or applicable requirements change. The latest version will be published on this page with its revision date.
