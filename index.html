PHOTO WORKFLOW GUIDE

Make images work wherever you need them.

A few practical notes to help you choose the right image size, file type and editing tool.

Choose the right dimensions

Start with the size required by the destination. Square images are useful for profile pictures and square social posts; vertical 9:16 layouts are commonly used for full-screen stories; and 16:9 is a familiar landscape video and presentation shape. Use the aspect-ratio lock to avoid accidental stretching. If you need a different shape, crop first and resize second.

Crop without distortion

Use the live crop frame to select the important part of a photo. Drag inside the frame to reposition it, then use the handles to change its size. A fixed ratio keeps the crop shape consistent. Cropping removes pixels outside the selected area; it does not add detail to a small or blurry source image.

JPG, PNG or WebP?

JPG is widely compatible and works well for photographs, but it does not preserve transparent areas. PNG is useful for graphics, screenshots and transparency. WebP can provide a compact file with good visual quality, although compatibility depends on the receiving app or workflow. Keep an original copy before converting.

Compress for faster sharing

For JPG and WebP, lower quality settings usually reduce file size but can introduce visible artifacts around fine detail and text. Start around 75–85% for everyday photographs, compare the preview or output, and increase quality when small details matter. Resizing the long edge can reduce file size further.

Prepare a print-size ID photo

Select the required physical dimensions and print resolution, then check the exported pixel size. The passport tool uses a centered crop and a white background. It does not detect the face, adjust eye position, validate expression or certify compliance; official photo rules vary by country and application, so review them before using the output.

When background removal works best

The background remover samples a color and makes similar pixels transparent. It is most effective when the background is plain and evenly lit and contrasts strongly with the subject. Hair, shadows, reflections and objects sharing the sampled color may need manual retouching in a more advanced editor.

Are my photos uploaded to PixelCraft Studio?

The editor processes selected image files in your browser and does not send photos to a PixelCraft image-processing server. Your website host may still keep ordinary server access logs.

Can I process multiple photos together?

Yes. Batch resize, bulk compression and format conversion accept multiple files. Outputs are provided as individual download links so you can choose which processed files to save.

Does the background remover use AI?

No. It uses solid-color sampling and chroma-key processing in the browser. It is not an AI model that recognizes people or separates complex objects from their surroundings.
